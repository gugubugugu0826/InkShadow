# InkShadow 下一阶段产品重构基线

> 2026-08-22 当前冲突规则：附件提出直接模式中“一次点击即授权一次远程生成并自动写入”的新产品目标，但附件同时被要求与用户直接指令区分。当前实现中，直接模式和专业模式的所有生成结果都先保持隔离；每次远程发送都先披露精确目标、范围、次数、费用与隐私，作者明确选择“使用这版”后才写入正文并创建不可变版本。附件提出的一次点击远程授权和自动写正文仍需用户独立明确授权，未获授权前不得写成已完成。

> 适用范围：桌面端个人创作主链路、Model Hub、后续小说智能内核

本目录是 2026-08-01 起的产品重构执行基线。它不删除旧文档中仍然有效的安全、数据、
同步和商业约束，但在首页、创作工作区、开书流程、导入改写和模型配置方面取代旧的
“系统模块驱动”信息架构。

0.2.17 的当前产品增量坚持同一安全边界：编辑器常驻开头或续写入口，选区任务只在当前有效选区出现；直接写作和专业创作共用单一“本次要求（可选）”及短、中、长篇幅，自定义目标只在高级设置出现。正文类任务统一采用安全与隐私、权威正文与锁定事实、当前任务、作者本次要求、规划与设定、实际采用技能、偏好和默认值的优先级，并在隔离结果进入作者决定前拒绝解释、分析、代码块、结构化载荷和内部标记。资料编译优先保留最新正文和必需事实，再处理可选旧资料；章节摘要按来源不可变版本判断状态并在本机重建；所有读取作品资料的远程路线在项目仍保留私密章节时失败关闭。自定义技能只按明确任务范围参与已经接入的资料编译。本轮不新增迁移，不修改任何已发布迁移或校验值。完整门禁、真实安装和人工验收的结论只能由本轮当前运行证据给出。

## 冲突处理

1. 不破坏本地正文、版本、恢复草稿、AI 建议版本和密钥安全；
2. 本目录的普通用户体验与实施顺序；
3. `docs/PROJECT.md`、`docs/PLAN.md`、`docs/PRD.md`、`docs/SPEC.md` 中仍然有效的系统约束；
4. 历史页面清单、状态标签和执行记录。

任何 `IMPLEMENTED`、`VERIFIED` 或历史测试报告，都不能替代对当前工作树和真实用户调用链的
重新验证。当前没有 44/44 VERIFIED 结论；真实 Provider、Windows 200% 缩放、安装/升级和百万字
项目仍须在相应环境单独验收。
