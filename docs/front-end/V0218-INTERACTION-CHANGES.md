# 0.2.18 交互修复记录

当前为修复工作区，不是已发布能力清单。

一句话设定与批量设定采用同一套逐条审阅和本地恢复流程。每个非空原句保留来源，未知句子由作者选择类型；保存只进入待确认区。此前单句入口直接转到正式导入的验收契约由本轮要求替代，相应测试改为检查逐条实际保存、原句恢复及零远程发送。

技能创建明确区分整理预览、保存、启用和实际采用。自然描述中的规则不能由默认文案替代。

资料抽屉使用独立的中文摘要，不直接展示请求中的内部类型和结构化字段。详情开关参与弹窗焦点路径，折叠内容不参与焦点循环。普通字数不显示技术上限，但校验上限不变。

基本规划安排前置到创作任务安排页；需要额外能力检查时仍先披露，只有作者明确确认才发送。

宽屏正文保留约 56% 可用编辑区域，右侧助手上限随可用区域变化；窄屏仍使用抽屉。顶栏分身份行与操作行，助手折叠后仍有主要生成入口。发送摘要显示要求前 60 个文字，完整要求可展开；这取代旧版“只显示已填写”的约定。

当前工作区已通过四个目标宽度、深浅主题和等效 200% 的浏览器布局回归，以及详情鼠标、键盘、模拟触摸、焦点返回、规则锁定与刷新回读。尚不是最终提交门禁；真人视觉、真人触摸与真实系统缩放未执行。

历史关系摘要只显示唯一相关句；完整原始依据保留在高级详情中，不改写历史范围或未知扩展。TXT 导出保留字内和转义下划线。PDF 继续明确为图像型，不声称具备可搜索文字层。
