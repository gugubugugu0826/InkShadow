## 三、编辑器状态模型与篇幅策略

### 3.1 单一要求输入

普通界面只保留一个 `本次要求（可选）`。可见输入相同，但存储键包含：

`项目 + 章节 + 正文版本 + 当前会话 + 任务类型 + 选区范围`

- 续写使用文档级身份，选区任务必须带非空的精确范围。
- 改写、润色、扩写和缩写分别保存，不会把上一任务要求自动带入下一任务。
- 路由、章节或版本变化后，旧异步恢复不能覆盖当前状态。
- 损坏草稿不会被删除或覆盖；界面显示本地保存异常，原始字节保留以供诊断。
- 确定失败和结果待核对都会保留本任务要求；只有生成成功，或作者在发送前明确取消，才清除准确身份下的草稿。
- 0.2.16 的项目级旧要求不会静默跨章节使用，只提供“确认用于当前章节”的显式迁移入口。

### 3.2 篇幅与自然停止

| 普通档位 | 对用户的说明               | 内部目标范围                     | 自然停止条件                                                   |
| -------- | -------------------------- | -------------------------------- | -------------------------------------------------------------- |
| 短       | 一小段推进                 | 800–1,200 可见字符，目标 1,000   | 完成一个局部动作、发现或对话节点后停止，不开启新事件           |
| 中       | 一个完整场景               | 1,800–2,500 可见字符，目标 2,200 | 完成当前场景主要推进，并留下自然衔接点                         |
| 长       | 一场完整事件或情绪推进     | 3,000–5,000 可见字符，目标 4,000 | 一场事件或情绪变化形成阶段性结果后收束，不再开启新的完整事件   |
| 高级目标 | 目标字数，允许约 ±20% 浮动 | 200–12,000 可见字符内按目标计算  | 达成作者目标的阶段性结果后收束，不为接近数字重复或另起无关事件 |

上述数字只用于内部安全、费用和自动化验证；短、中、长的普通界面不承诺精确字数。长档资料预算仍为 64,000 个本机估算单位，没有为压缩体积降低提示词或正文质量。

高级目标会以目标值和 80%–120% 可见字符范围进入最终提示词、披露、进度、治理快照和任务元数据。12,000 字目标及 14,400 字结果上限可跨重启回读；无效或输入中的中间数字不会持久化，也会在发送前失败关闭。旧 0.2.16 快照缺少新增字段时按“未记录高级目标”兼容读取，不伪造数值。

### 3.3 确认与一次发送

- 默认确认摘要以五项短句说明任务、模型与服务商、参考资料、一次发送、私密去向和费用。
- “查看详情”保留完整资料选择与省略原因、隐私去向、价格依据、预算和技术恢复信息。
- “在当前会话记住本次确认”默认不勾选，只有完整身份一致时才复用；复用时仍显示简短摘要。
- 确认前取消不发送；聚焦的一次派发用例验证确认后只调用一次，自动重试为零。
- 披露完成后，对任务、正文版本、模型、服务商、资料、隐私和输出合同计算不含正文的请求指纹；离线恢复、失败重试和最终发送都必须精确匹配，任一权威变化都会建立新任务、运行和幂等标识。

## 五、事实、摘要和检查结论

### 5.1 事实分类

真实样本“他忽然想起母亲笔记本里夹着的那张照片。”现在产生普通的待确认回忆事实：

- 建议分类：回忆；
- 证据：原句原文；
- 来源：准确章节和不可变版本；
- 范围：原句的 UTF-16 起止位置；
- 产生方式：本地确定性整理；
- 远程调用：0。

单独出现“母亲”等亲属词不再构成人物关系证据。核心关系只接受明确的归属关系句或双方关系句，不能补写原文没有的人名或关系变化。

### 5.2 摘要版本

- “已更新／摘要待更新”由摘要来源版本、当前不可变版本和内容校验值共同决定，字数差只作为内容说明。
- 未接受的生成结果不改变当前版本，因此不改变摘要来源判断。
- 本地重建读取当前不可变版本，写入来源版本、内容校验值和准确句子范围；派生失败不会回滚正文。
- 新摘要只在自身结构化值中记录明确的被替代事实标识，旧事实本身保持不变；作者主动弃用与自动替代不再混为一谈。

### 5.3 一致性调查

普通界面现在明确区分：

1. 已检查，未发现有证据的问题；
2. 证据不足，部分内容未能判断；
3. 本次未执行；
4. 检查失败。

只有携带当前准确文本依据的结论可以进入正式发现；证据不足的可能性不会升级为错误。
