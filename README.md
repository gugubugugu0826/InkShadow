# 墨影 InkShadow

InkShadow 是一款面向长篇小说作者的本地优先创作工作台。它把正文写作、故事规划、设定管理和一致性检查放在同一个桌面应用中，并让作者始终掌握模型生成内容是否进入作品的最终决定权。

当前版本为 InkShadow 0.2.14，面向 Windows 10／11 x64 提供。安装程序尚未取得 Authenticode 商业代码签名，因此 GitHub 将其标记为未签名预发行；Windows 可能显示“未知发布者”。请只从本仓库的正式发布页下载，并在安装前核对同页 `SHA256SUMS`。重要作品不应只保留一个副本。

## 适用场景

- 从一句灵感开始新故事，在确认开书方案后继续创作；
- 导入已有小说，在保留原文的前提下试改和整理；
- 不借助模型直接创建空白作品并立即写作；
- 使用专业创建填写方向、人物、世界和写作约束；故事设定先等待作者确认；
- 管理长篇作品的章节、人物、地点、事件、关系和故事事实；
- 对选中的正文进行扩写、改写、润色或缩写，并在接受前比较结果；
- 检查矛盾、视角、人物知识、人物说话一致性、伏笔和节奏问题；
- 通过版本历史、恢复草稿、备份和导出保护长期写作成果。

## 四个创作区域

项目内的一级导航保持为四个面向作者的区域：

- **正文**：章节写作、自动保存、恢复草稿、版本历史与模型建议比较；
- **规划**：故事方向、章节安排和可逐项采纳的规划建议；
- **设定**：人物、地点、关系、事件以及带原文依据的待确认设定；
- **检查**：基于具体章节和版本证据呈现的问题与处理记录。

模型路由、任务记录、资料选择过程和诊断信息保留在设置或高级诊断中，不会占据普通创作导航。

## 正文与版本保护

模型生成结果会先成为与正文隔离的建议版本。未接受的开头、续写或选区处理结果不会覆盖正文；只有作者明确选择使用后，应用才会原子创建新的不可变版本。由正文派生的设定、摘要、索引或检查结果可以重新整理，其失败不会回滚已经接受的正文。

恢复草稿和历史建议会单独保存，不会被误认为已经接受的正文，也不会悄悄改变下一次创作任务。

## 本地优先与私密章节

- Windows 桌面端无需注册即可开始写作，项目正文默认保存在本机；
- 接口密钥保存在系统凭据库，不写入项目数据库；
- 章节可以设为“仅本机”，此类章节禁止发送给远程模型；
- 云同步默认关闭，当前公开预览不提供托管云服务；
- 诊断和普通日志不得包含凭据、完整正文、完整灵感或完整模型输出。

## 模型连接与发送确认

InkShadow 可连接 DeepSeek、OpenAI、通义千问、豆包、智谱 GLM、Gemini、Claude、Ollama 及自定义兼容接口。连接已保存、最近验证、模型目录和具体创作任务是否可用会分别核对；连接尚待重新核对时不会被伪装成成功，也不会在作者不知情时发起付费验证。

每次发送作品资料前，页面会说明服务商、模型、资料范围、隐私去向、最多发送次数、自动重试次数以及当前可取得的费用信息。确认前取消保持零次发送；发送结果不确定时不会自动重发。

## 导入、导出与备份

应用支持安全导入 TXT、Markdown、DOCX、EPUB、静态 HTML 和可提取文本的 PDF。项目可导出为 Markdown、EPUB、DOCX、PDF 等真实文件；导出私密章节需要作者明确选择。

设置页提供手动备份、自动备份、恢复和本地数据库检查。升级或更换安装包前，请先创建备份，并将备份复制到独立位置。恢复操作会先核对备份完整性，不会通过清空数据库解决迁移问题。

## 安装与首次使用

系统要求：

- Windows 10 或 Windows 11，x64；
- Microsoft Edge WebView2 Runtime。

安装步骤：

1. 从 [InkShadow 0.2.14 发布页](https://github.com/gugubugugu0826/InkShadow/releases/tag/v0.2.14) 下载安装程序、来源清单和 `SHA256SUMS`；不要从非发布渠道获取同名安装包；
2. 使用 SHA-256 工具核对安装程序与校验文件；
3. 运行安装程序。未签名预览可能触发 Windows 安全提示，请先确认文件来自上述 Release；
4. 首次启动后可直接写作，也可在需要模型协助时再连接自己的服务；
5. 从旧版本升级前先在“设置 → 导入与导出”创建备份。

所有历史标签和附件保持不可变。当前下载、安装包大小、准确哈希、已知限制与验证范围以 [GitHub Releases](https://github.com/gugubugugu0826/InkShadow/releases) 中对应版本页面为准。

## 已知边界

- 0.2.14 安装程序未进行商业代码签名，Windows 可能显示安全提示；发布页同时提供来源清单和 SHA-256 校验文件。
- 模型可用性、响应时间、费用和输出质量取决于作者选择的服务商、模型及账户；费用未知时应用会如实说明，不会伪造金额。
- 浏览器预览不能替代 Windows 桌面端的系统凭据库、原生保存对话框、SQLite 和安装程序能力。
- 在覆盖升级、卸载、重装或迁移数据前，请先创建数据库备份，并把备份复制到独立位置。

## 源码构建

需要 Node.js 24+、pnpm 11+、Rust 1.85+、Microsoft C++ Build Tools 和 WebView2 Runtime。

```powershell
pnpm install --frozen-lockfile
pnpm dev:desktop
```

浏览器前端预览：

```powershell
pnpm dev
```

浏览器预览不包含完整的 Tauri、系统凭据库和原生 SQLite 能力。

主要质量门禁：

```powershell
pnpm check
pnpm test:e2e:release
pnpm check:rust
```

未签名 Windows 发布包只能从工作区干净、来源唯一的提交构建：

```powershell
$env:CI = "true"
pnpm release:candidate:unsigned
Remove-Item Env:CI
```
